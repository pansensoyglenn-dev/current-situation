🚀 GitHub Auto-Deploy

When enabled, every article you save is automatically pushed to a GitHub repo as a markdown file (with its photo, if any). Requires a Personal Access Token with Contents: read & write permission on the repo. The token is stored only on this device, never sent anywhere except GitHub's API.

✨ AI Summary & Tags

Add your own Anthropic API key to auto-generate a short summary and a handful of tags for each article. The key is stored only on this device and sent directly to Anthropic's API when generating — never to any other server. Get a key at console.anthropic.com.

🗄️ Backup & Restore

Download everything on this device — articles, photos, videos, and your saved GitHub/AI settings — as files you can keep, then load back in later if you want to make changes. ⚠️ The backup file includes your saved GitHub token and Anthropic API key in plain text — keep it private.

📤 Deploy to GitHub

Export all articles as markdown files ready for your GitHub repository. Files are organized by category and include YAML frontmatter for Jekyll/GitHub Pages compatibility.
