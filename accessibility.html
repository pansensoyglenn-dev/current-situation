Accessibility

Last updated: August 25,2026

The Commonplace aims to be usable by as many people as possible, including those using screen readers, keyboard-only navigation, or browser zoom.

What's in place today

  • Semantic HTML landmarks (navigation, main content, footer) for screen readers
  • Visible focus states on interactive elements when navigating by keyboard
  • Text scales with browser zoom and respects device font settings
  • Color choices maintain reasonable contrast between text and background
